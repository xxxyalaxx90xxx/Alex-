## 📖 Verwendung

### Installation

```bash
# Repository klonen
git clone https://github.com/xxxyalaxx90xxx/Alex-.git
cd Alex-

# Installationsskript ausführbar machen
chmod +x install.sh

# Installation starten
./install.sh
```

### Performance-Optimierung

```bash
# Alle Optimierungen aktivieren
./performance-optimizer.sh turbo

# Performance-Test durchführen
./performance-optimizer.sh test

# System-Monitoring
./performance-optimizer.sh monitor
```

### API-Management

```bash
# Alle APIs einrichten
./api-manager.sh setup

# API-Status anzeigen
./api-manager.sh status

# APIs testen
./api-manager.sh test
```

### Repository-Management

```bash
# Repository automatisch klonen und einrichten
./auto-clone.sh facebook/react

# Mit bestimmtem Branch
./auto-clone.sh vuejs/vue main
```

## 🆘 Troubleshooting

### Problem: pkg update schlägt fehl
```bash
termux-change-repo
```

### Problem: Kein Speicherplatz
```bash
pkg clean
apt autoremove
./performance-optimizer.sh clean
```

### Problem: Permission denied
```bash
termux-setup-storage
chmod +x *.sh
```

### Problem: GitHub Authentication
```bash
gh auth refresh
# oder
gh auth login
```
